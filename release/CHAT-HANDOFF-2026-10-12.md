### 1.2 Android-пристрій для тестів
На Mac (Intel i7-4770HQ, 2014) є `~/Library/Android/sdk` з `emulator` і `platform-tools`, але **немає жодного AVD і system image**. Варіанти (власник ще не вибрав):
1. **Реальний телефон по USB** (рекомендовано): режим розробника → «Налагодження через USB» → підключити й підтвердити. Далі `adb install` збірки напряму.
2. **Емулятор**: потрібне завантаження cmdline-tools + образу Android 15 (~1,5 ГБ з dl.google.com) — **спитати дозволу на завантаження**; на цьому Mac буде повільно.

### 1.3 Великі файли (AAB 39–57 МБ) у Play Console
- Інструменти браузера передають файли лише до 10 МБ. Computer use у сесії не було.
- Рішення: скрипт **`tools/aab-serve.py`** (у `Desktop/Button/tools/`, не в git). Слухає лише 127.0.0.1, віддає один файл на `/file` тільки для `https://play.google.com` (CORS), вимикається після однієї передачі або через 10 хв. Запуск: `python3 -I /Users/serhii/Desktop/Button/tools/aab-serve.py <шлях-до-aab> [port]` у фоні, потім у вкладці Play Console через JS: `fetch('http://127.0.0.1:8418/file')` → `File` → `DataTransfer` → `input[type=file]` + подія `change`.
- Класифікатор auto-mode блокує запуск без правила. **Власник має сам додати** в `Desktop/Button/.claude/settings.local.json` (Claude змінювати власні дозволи не може — «Self-Modification»):
  ```json
  { "permissions": { "allow": [ "Bash(python3 -I /Users/serhii/Desktop/Button/tools/aab-serve.py:*)" ] } }
  ```
- Альтернатива: власник вмикає Computer use (Налаштування → Цей комп'ютер), але браузери там лише «read», тож надійніший шлях — скрипт.
